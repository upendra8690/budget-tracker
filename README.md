\# 🚀 Ultra Smart Budget Tracker Pro Max 💰 (2026 Edition)



A \*\*professional CLI-based Budget Tracking System\*\* built using Python.  

This project helps users manage weekly budgets, track spending, analyze expenses, and export reports.



---



\## 📌 Project Features (Company-Level)



✅ Weekly budget setup system  

✅ Add purchases with unique ID  

✅ Cart purchase mode (multiple items at once)  

✅ Edit / Delete / Search purchases  

✅ Undo last delete (rare feature)  

✅ Sort purchases by price / date / category  

✅ Category-wise spending summary  

✅ Spending bar chart (visual CLI report)  

✅ Daily spending report  

✅ Analytics dashboard (prediction + insights)  

✅ Discount calculator  

✅ Export purchases to CSV \& JSON  

✅ Backup system (timestamped backups)  

✅ Reset week option  

✅ Safe auto-save JSON (prevents file corruption)  

✅ Auto data-fix (spent recalculated automatically)



---



\## 🛠️ Technologies Used



\- \*\*Python 3\*\*

\- JSON File Handling

\- CSV Export System

\- CLI Dashboard System

\- UUID System (unique purchase IDs)
